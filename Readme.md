# MehdiLabs Cours V2.0

Bienvenue dans le projet **MehdiLabs Cours V2.0** !

Ce projet est une application développée en **C#**.
## 🚀 Prérequis

Pour utiliser ce projet, vous devez installer :
- [.NET SDK](https://dotnet.microsoft.com/download)
- Un éditeur de code comme [Visual Studio](https://visualstudio.microsoft.com/) ou [Visual Studio Code](https://code.visualstudio.com/)

## 🔑 Clés API

Ce projet utilise plusieurs fournisseurs d'intelligence artificielle. Vous pouvez générer des clés API pour les services que vous souhaitez utiliser :

- **OpenAI** : [Récupérer une clé API OpenAI](https://platform.openai.com/api-keys)
- **Anthropic (Claude)** : [Récupérer une clé API Anthropic](https://console.anthropic.com/settings/keys)
- **Google (Gemini)** : [Récupérer une clé API Google AI Studio](https://aistudio.google.com/app/apikey)
- **Groq** : [Récupérer une clé API Groq](https://console.groq.com/keys)
- **Mistral AI** : [Récupérer une clé API Mistral](https://console.mistral.ai/api-keys/)
- **DeepSeek** : [Récupérer une clé API DeepSeek](https://platform.deepseek.com/api_keys)
